Flow Identified: Wellness Dashboard

Functionality:

The Wellness Dashboard flow in VidyaNXT is designed to provide teachers in under-resourced Indian schools with a comprehensive tool to monitor their mental and emotional well-being. It offers a centralized interface displaying wellness metrics, alerts, notifications, and personalized recommendations. The system leverages AI-driven insights (via Gemini AI) to analyze teacher data, detect stress levels, and suggest actionable support, aligning with VidyaNXT’s goal of supporting teacher sustainability in challenging environments.

Components and Architecture Involved
Frontend Components
The frontend is built as a React-based Progressive Web App (PWA), with the following components dedicated to the Wellness Dashboard flow:

src/pages/WellnessDashboard.jsx
Purpose: The main dashboard page that serves as the entry point for wellness monitoring.
Key Responsibilities:
Fetches and displays comprehensive wellness data for the teacher.
Manages state for teacher data, dashboard data, loading, and errors.
Handles navigation and alert acknowledgment.
src/components/WellnessMetrics.jsx
Purpose: Displays detailed wellness metrics and charts.
Key Responsibilities:
Fetches analytics data for specified timeframes (e.g., 7 days, 30 days).
Formats data for visual representation (e.g., charts, distributions).
src/components/WellnessAlerts.jsx
Purpose: Lists active wellness alerts.
Key Responsibilities:
Displays alerts with urgency levels and allows teachers to acknowledge them.
Provides visual cues (icons, colors) based on alert priority.
src/components/WellnessAnalytics.jsx
Purpose: Provides trends and analytical insights into wellness data.
Key Responsibilities:
Fetches and displays analytics for a selected timeframe.
Handles loading and error states.
src/components/WellnessNotifications.jsx
Purpose: Manages wellness-related notifications.
Key Responsibilities:
Fetches and displays notifications.
Allows marking individual or all notifications as read.
src/components/WellnessRecommendations.jsx
Purpose: Shows AI-generated wellness recommendations.
Key Responsibilities:
Fetches and filters recommendations (e.g., active, completed).
Allows teachers to mark recommendations as completed or dismissed.
Backend Components
The backend is powered by Firebase Cloud Functions and Firestore, with additional AI integration via Gemini:

functions/src/functions/wellness.js
Key Functions:
getEnhancedTeacherDashboard:
Fetches teacher data, wellness metrics, and recent challenges.
Returns a comprehensive dashboard dataset.
acknowledgeWellnessAlertFunction:
Marks a wellness alert as acknowledged in Firestore.
getWellnessAnalytics:
Retrieves analytics data for a specified timeframe (e.g., 7d, 30d, 90d).
getWellnessDashboard:
Fetches dashboard data with AI-generated insights from the WellnessAgent.
functions/src/services/wellness.js
Utility Functions:

functions/src/agents/wellness-agent.js
WellnessAgent Class:
Uses Gemini AI to analyze wellness indicators from challenges and chat sessions.
Generates insights, recommendations, and dashboard summaries.
Architecture Overview
Frontend: React PWA with modular components for each wellness feature, using React Router for navigation.
Backend: Serverless architecture with Firebase Cloud Functions handling API logic and Firestore for real-time data storage.
AI Integration: Gemini AI powers the WellnessAgent for intelligent analysis and recommendations.
Data Flow: Frontend components fetch data via HTTPS callable functions, which interact with Firestore and the WellnessAgent.
