Functionality:

Architecture Overview
Frontend: React PWA with Vite for fast builds, Tailwind CSS for styling, and Firebase SDK for backend integration. Offline support is enabled via service workers and IndexedDB (public/ assets).
Backend: Firebase Cloud Functions with a multi-agent architecture. Agents (ai-chat-agent.js, wellness-agent.js) leverage Google Gemini for AI tasks, orchestrated by breadboards.
Data Storage: Firestore stores teacher profiles, wellness data, and chat logs, with offline sync capabilities.
Integration: Frontend communicates with backend via HTTPS callable functions, with Gemini providing AI-driven insights.
