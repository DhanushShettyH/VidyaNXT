
Flow Identified: Peer Chat
The code implements the Peer Chat flow, which enables teachers to connect with their peers (including an AI peer) for real-time communication. This flow is a core part of the Peer-to-Peer Teacher Network feature in VidyaNXT, designed to help teachers collaborate and share knowledge in under-resourced Indian schools.

Components and Architecture Involved
Frontend Components
PeersList Component (src/pages/PeersList.jsx):
Displays a list of peers, including an AI peer, with their display names and unread message counts.
Handles navigation to existing chat conversations or alerts users if no conversation exists.
ChatWindow Component (src/pages/ChatWindow.jsx):
Manages the chat interface, displaying real-time messages and allowing users to send new messages.
Marks conversations as read when opened and ensures the chat scrolls to the latest message.
App.jsx:
Defines routing for the application, including paths for the peer list (/peers) and chat window (/chat/:convoId and /chat/list).
Backend Components
startChatWith Cloud Function (functions/src/functions/chat.js):
Finds or creates a one-on-one conversation between two teachers.
Adds peers to each other's network in Firestore.
markAsRead Cloud Function (functions/src/functions/chat.js):
Resets the unread message count for a teacher in a specific conversation.
incrementUnread Firestore Trigger (functions/src/functions/triggers.js):
Automatically increments the unread message count for the recipient when a new message is sent.
chat.js Service Functions (functions/src/services/chat.js):
Provides utility functions like findConversation, createConversation, getConversationMessages, addMessage, updateConversationActivity, and addPeersToNetwork to manage chat-related operations.
Architecture Overview
Modular Design: The code separates frontend components (PeersList, ChatWindow) from backend logic (startChatWith, markAsRead, incrementUnread), ensuring maintainability.
Real-time Database: Firestore provides real-time updates for peer lists, messages, and unread counts via onSnapshot.
Serverless Backend: Firebase Cloud Functions handle chat initiation and unread count management, ensuring scalability.
Event-Driven Triggers: Firestore triggers automate unread count increments when new messages are sent.
